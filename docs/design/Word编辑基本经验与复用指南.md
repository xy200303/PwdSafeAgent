# Word 编辑基本经验与复用指南

## 1. 文档目的

本文沉淀 Word 编辑中的基础经验、排版技术和模板维护注意事项，适用于方案、报告、制度、说明书等正式文档的编制与复用。

目标是让不同人员在同一套规范下编辑 Word，减少格式漂移、编号错乱、目录失效、表格变形和模板损坏等问题。

## 2. 核心原则

1. 优先使用样式，不手工堆格式。
2. 优先使用 Word 的结构化功能，不用空格、空行和手动编号模拟排版。
3. 正文内容和版式控制分开处理。
4. 修改模板前先备份，修改完成后做完整检查。
5. 对外发布前统一更新目录、页码、题注、交叉引用和域。
6. 多人协作时保留修订记录，定稿时统一接受修订并清理批注。

## 3. 推荐编辑流程

### 3.1 开始前

1. 复制一份模板或上一版文档，避免直接覆盖原始模板。
2. 打开“显示/隐藏编辑标记”，检查段落标记、分页符、分节符、空格和换行。
3. 确认页面设置，包括纸张、页边距、页眉页脚、装订线和方向。
4. 确认文档使用的字体、字号、行距、段前段后和标题级别。
5. 如果文档有目录，先确认标题样式是否完整应用。

### 3.2 编辑中

1. 先写内容，再统一调整格式。
2. 标题使用“标题 1、标题 2、标题 3”等样式，不手动加粗放大模拟标题。
3. 正文使用正文样式，不从其他文档直接带格式粘贴。
4. 复制外部内容时优先使用“只保留文本”，再套用本模板样式。
5. 编号列表使用自动编号，多级标题使用多级列表绑定标题样式。
6. 表格先确定列含义和宽度，再填内容。
7. 图片、图表和表格应添加题注，方便生成目录和交叉引用。
8. 需要换页时使用分页符，不连续敲空行。
9. 需要改变页眉页脚、页码或页面方向时使用分节符，不随意插入多余空段落。

### 3.3 定稿前

1. 全选文档后更新域，刷新目录、页码、题注和交叉引用。
2. 检查标题层级是否连续，目录是否缺项或多项。
3. 检查编号是否从正确位置开始，是否存在手动编号混入。
4. 检查表格是否跨页断裂、列宽混乱或表头缺失。
5. 检查图片是否清晰、位置稳定、题注编号正确。
6. 检查页眉页脚、页码、封面、目录和正文起始页是否符合要求。
7. 删除多余空格、空段、批注、修订痕迹和隐藏的临时内容。
8. 另存为 PDF 后再通读一遍，确认最终交付效果。

## 4. 样式使用经验

### 4.1 样式是 Word 长文档的基础

样式用于统一控制标题、正文、表格、图注、页眉页脚等格式。成熟文档不应依赖局部手动格式，因为手动格式很难统一维护，也容易在复制、合并和导出 PDF 时出现差异。

常见样式建议：

| 类型 | 推荐做法 | 避免做法 |
| --- | --- | --- |
| 一级标题 | 使用标题 1 | 手动加粗、放大、居中 |
| 二级标题 | 使用标题 2 | 手动输入编号 |
| 正文 | 使用正文或模板指定正文样式 | 从网页或其他文档带格式粘贴 |
| 图题 | 使用题注或图题样式 | 手动写“图 1” |
| 表题 | 使用题注或表题样式 | 手动写“表 1” |
| 页眉页脚 | 使用模板样式 | 每页单独复制修改 |

### 4.2 修改样式而不是逐段修改

如果发现全篇正文行距、缩进或字号不一致，应优先修改对应样式，而不是逐段刷格式。这样可以一次影响所有使用该样式的内容，也便于后续维护。

### 4.3 谨慎使用格式刷

格式刷适合少量局部修正，不适合作为长期排版手段。大量使用格式刷容易把不需要的段前段后、缩进、编号级别和隐藏格式一起复制过去。

## 5. 标题、编号和目录

### 5.1 标题层级

标题层级应表达文档结构：

1. 标题 1 对应章。
2. 标题 2 对应节。
3. 标题 3 对应小节。
4. 不建议跳级，例如从标题 1 直接到标题 3。

### 5.2 多级编号

正式报告通常需要 `1`、`1.1`、`1.1.1` 这种多级编号。建议将多级列表绑定到标题样式，而不是在标题前手动输入编号。

手动编号的问题：

1. 插入新章节后不会自动更新。
2. 删除章节后容易漏改后续编号。
3. 生成目录时可能出现编号和标题不一致。
4. 交叉引用无法稳定使用。

### 5.3 目录维护

目录应基于标题样式自动生成。更新目录时可选择“只更新页码”或“更新整个目录”。如果新增、删除或改名了标题，应更新整个目录。

目录异常排查：

| 问题 | 常见原因 | 处理方式 |
| --- | --- | --- |
| 标题未进入目录 | 没有使用标题样式 | 套用正确标题样式 |
| 正文进入目录 | 正文误用了标题样式 | 改回正文样式 |
| 页码不对 | 域未更新 | 全选后更新域 |
| 目录层级混乱 | 标题级别错误 | 重新设置标题级别 |

## 6. 段落、换行和分页

### 6.1 段落和换行的区别

按 `Enter` 会产生新段落，按 `Shift+Enter` 会产生手动换行。正式文档中应尽量使用段落来表达内容结构，少用手动换行。

### 6.2 不用空行控制距离

段前段后距离应通过段落格式或样式控制，不应连续敲空行。空行会导致不同电脑、不同版本 Word 或导出 PDF 时版式不稳定。

### 6.3 分页符和分节符

需要新页面开始时使用分页符。需要改变页码、页眉页脚、页面方向或页边距时使用分节符。

常见场景：

| 场景 | 推荐功能 |
| --- | --- |
| 封面后另起一页 | 分页符 |
| 目录和正文使用不同页码格式 | 分节符 |
| 中间插入横向大表 | 分节符 |
| 某章必须从新页开始 | 标题样式中的段前分页 |

## 7. 表格编辑经验

### 7.1 表格结构优先

表格应先明确列名、列宽、数据类型和是否跨页，再填内容。不要在表格中大量使用空格对齐。

### 7.2 常用设置

1. 表头行重复：长表跨页时应启用表头行重复。
2. 固定列宽：正式文档中建议固定关键列宽，减少内容变化导致的表格变形。
3. 单元格边距：通过表格属性设置，不靠空格缩进。
4. 垂直对齐：按内容类型统一设置为顶端或居中。
5. 跨页断行：长文本表格可允许跨页，关键记录表可禁止单行跨页。

### 7.3 表格常见问题

| 问题 | 处理方式 |
| --- | --- |
| 表格超出页面 | 调整列宽、改横向页面或缩短字段 |
| 表格断页难看 | 设置表头重复，必要时禁止行跨页 |
| 单元格内容挤压 | 调整列宽、行距或拆分字段 |
| 边框不一致 | 统一使用表格样式或边框设置 |
| 从 Excel 粘贴后格式乱 | 优先粘贴为文本或匹配目标格式 |

## 8. 图片、图表和题注

### 8.1 图片插入

图片建议使用“嵌入型”或模板指定的环绕方式。正式报告中如果没有特殊排版需求，嵌入型最稳定，不容易因页面调整发生漂移。

### 8.2 图片质量

1. 原图应足够清晰，避免先压缩再放大。
2. 截图前尽量放大窗口或使用高分辨率导出。
3. 网络拓扑、流程图等优先使用矢量图或高清图片。
4. 不要把含有大量文字的低清截图直接放入正文。

### 8.3 题注和交叉引用

图、表应使用 Word 题注功能。正文中引用图表时使用交叉引用，不手动输入“见图 3-2”。这样在插入或删除图表后，编号可以自动更新。

## 9. 页眉页脚和页码

页眉页脚通常与分节符相关。修改页眉页脚前要注意当前节是否启用了“链接到前一节”。

常见规则：

1. 封面通常不显示页码。
2. 目录可使用罗马数字或单独页码。
3. 正文通常从第 1 页开始重新编号。
4. 横向页面可能需要单独调整页眉页脚位置。
5. 删除分节符可能连带改变前后节的页面设置。

## 10. 粘贴和格式清理

### 10.1 推荐粘贴方式

从外部来源复制内容时，优先选择：

1. 只保留文本。
2. 匹配目标格式。
3. 粘贴后重新套用模板样式。

### 10.2 清理异常格式

如果某段文字格式异常，可以尝试：

1. 清除格式后重新套用样式。
2. 检查是否存在手动换行、空格缩进或隐藏字符。
3. 使用样式窗格查看当前段落应用的样式。
4. 对编号异常的段落重新应用多级列表级别。

## 11. 审阅、批注和多人协作

### 11.1 修订模式

多人协作时建议开启修订。合并反馈时由负责人统一接受或拒绝修订，避免每个人各自定稿。

### 11.2 批注管理

批注适合提出问题和修改建议，不适合承载最终内容。定稿前应确认所有批注已处理并删除。

### 11.3 版本命名

建议文件名包含项目、文档类型、版本号和日期，例如：

```text
项目名称-密码应用方案-v1.2-20260605.docx
```

不要长期使用“最终版”“最终修改版”“最终最终版”这类文件名。

## 12. 模板维护注意事项

本节适用于维护 Word 模板、自动生成模板或需要被程序读取的 Word 文档。

### 12.1 不随意改动模板结构

模板中可能包含样式、编号定义、内容控件、书签、域、页眉页脚、目录和程序识别锚点。维护模板时不能只看可见文字，还要关注隐藏结构。

如果模板被程序使用，应特别注意：

1. 不删除内容控件、书签或隐藏锚点。
2. 不随意复制粘贴带锚点的整段内容，避免出现重复 ID。
3. 不手动改名程序约定的结构标识。
4. 修改章节标题后，同步更新模板结构说明或 JSON 配置。
5. 修改表格结构后，同步调整字段映射和生成逻辑。
6. 保存后使用自动化测试或样例生成验证模板仍可写入。

### 12.2 样式和编号是模板资产

模板的样式、编号、表格样式和页面设置属于核心资产。不要为了局部效果随意新增大量样式，也不要把外部文档的样式批量带入模板。

建议维护规则：

1. 新增样式前先确认现有样式是否可复用。
2. 样式名称应表达用途，而不是表达某一次临时效果。
3. 标题编号应统一通过多级列表管理。
4. 表格样式应覆盖常见表头、正文、边框和对齐方式。
5. 模板变更后保留简短变更说明。

### 12.3 内容控件和书签

内容控件和书签适合做结构定位。人工编辑时它们通常不明显，但程序可以依赖它们定位插入区域。

维护建议：

1. 开启开发工具选项卡，必要时查看内容控件属性。
2. 使用稳定、唯一、语义清晰的 tag 或书签名。
3. 不在同一文档内复用同一个结构 ID。
4. 对需要重复生成的表格行、图片槽位和章节正文单独设置锚点。
5. 修改锚点后同步更新代码、配置和测试用例。

## 13. 常见问题速查

| 问题 | 可能原因 | 快速处理 |
| --- | --- | --- |
| 目录不更新 | 域未刷新 | 全选后更新域 |
| 标题编号乱 | 手动编号或列表绑定异常 | 重新应用标题样式和多级列表 |
| 正文格式不一致 | 混入外部格式 | 清除格式后套用正文样式 |
| 图片位置漂移 | 使用了浮动环绕 | 改为嵌入型或固定锚点 |
| 页码从错误位置开始 | 分节符或页码设置错误 | 检查分节符和页码格式 |
| 表格跨页异常 | 行属性或表头设置不当 | 设置表头重复和跨页规则 |
| PDF 版式变化 | 字体缺失或对象浮动 | 嵌入字体、固定图片和表格布局 |
| 模板生成失败 | 锚点、字段或表格结构被改动 | 对照模板说明恢复结构 |

## 14. 可复用检查清单

### 14.1 内容检查

- 标题、章节、图表和附件是否完整。
- 术语、单位、名称和缩写是否前后一致。
- 表格字段是否齐全，空值是否有说明。
- 图片是否清晰，题注是否准确。
- 引用、依据和参考资料是否可追溯。

### 14.2 格式检查

- 标题是否全部使用标题样式。
- 正文是否使用统一正文样式。
- 编号是否自动生成且连续。
- 目录是否完整且页码正确。
- 页眉页脚是否符合模板要求。
- 表格是否未超出页边距。
- 图片是否未遮挡文字或跨页错位。

### 14.3 交付检查

- 已更新全部域。
- 已清理批注和修订。
- 已删除临时内容和多余空段。
- 已另存为 PDF 并核对版式。
- 已按版本命名规则保存。
- 已保留可编辑 Word 源文件和最终 PDF。

## 15. 建议复用方式

1. 新人培训时，可先阅读第 2 至第 10 节，掌握基础编辑规范。
2. 编制正式报告时，可直接使用第 14 节作为交付前检查表。
3. 维护模板或自动生成文档时，应重点参考第 12 节。
4. 出现格式问题时，可优先查第 13 节定位原因。
5. 团队可根据项目要求，把本文补充为自己的 Word 编制规范。
